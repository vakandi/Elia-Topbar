EliaTopBar

Native macOS menu bar command center for the Elia agent ecosystem. Live subworker status, run popup animations, real-time logs, one-click triggers — plus full Colima instance control.

⬇️ Download DMG View on GitHub

The full dashboard menu & per-agent controls, live from the menu bar.

What Is This?

EliaTopBar sits in your macOS menu bar and gives you real-time command over the Elia agent ecosystem — without opening a browser or terminal. It connects over WebSocket to the Elia FastAPI server and turns every subworker into a live, actionable dashboard row.

🟢 Live agent states

Running, idle, disabled, error, done — pushed over WebSocket, never polled.

📍 Per-agent menu bar icons

Each running subworker gets its own top-bar photo with a state-colored ring.

💬 Run popup animation

When an agent starts, its photo drops from the icon with a live output bubble — visible even over fullscreen video.

🖱️ Full LogViewer

Click an agent photo to browse sessions, messages, reasoning and tool calls — always clamped inside the screen.

⚡ One-click triggers

Manual Run Subworker dropdown, enable / disable, next run, schedule — everything from the menu.

⚙️ Topbar Settings

Agent photos side, live padding slider, run animation duration + test trigger. Zero permissions required.

❤️ Server health

Connection state, PID, restart count, reconnect — at a glance.

🐳 Colima control

Start / stop / restart instances, open a shell, inspect resources, launch at login.

Architecture

┌────────────────────────────────────────────────────────────────┐
│  EliaTopBar  (macOS menu bar app, Swift 5.9)                   │
│                                                                │
│   menu bar icon  ◄─── dynamic state (running / error / idle)   │
│   per-agent photos ◄── live fleet with state-colored rings     │
│   run popup      ◄─── photo drop + live bubble on run start    │
│   log popover    ◄─── click any agent photo                    │
└──────────────────────────────┬─────────────────────────────────┘
                               │ WebSocket (ws://localhost:5656/ws)
                               │ HTTP  (/status, /trigger, /enable,
                               │        /disable, /logs, /server/health)
                               ▼
┌────────────────────────────────────────────────────────────────┐
│  EliaAgent  (FastAPI in Docker)                                │
│                                                                │
│   subworker scheduler  ◄─── agents run on schedule or trigger  │
│   /ws real-time events  ─── initial_status, subworker_started, │
│                            run_log, subworker_completed, pong  │
└────────────────────────────────────────────────────────────────┘

EliaTopBar is the control surface; EliaAgent is the engine.

Quick Start

1 · Download

Grab EliaTopBar-vX.Y.Z-arm64.dmg from the latest release, open it and drag EliaTopBar to Applications.

2 · First launch

Ad-hoc signed, not notarized: right-click the app → Open, then confirm. Stubborn? xattr -dr com.apple.quarantine /Applications/EliaTopBar.app

3 · Connect

Make sure the EliaAgent server runs on localhost:5656. The app auto-connects — no config file, no env vars. Different host? Change Server URL…

Prefer building from source?

git clone https://github.com/vakandi/Elia-Topbar.git
cd Elia-Topbar
./build-app.sh          # ad-hoc signed
open EliaTopBar.app
