Features

Built for agent operators

Everything you need to monitor, trigger, and manage your Elia subworkers — without leaving the menu bar.

Live agent states over WebSocket

Running, idle, disabled, error, done — pushed from EliaAgent in real time via ws://localhost:5656/ws. Never polled, always fresh.

Per-agent menu bar icons

Each running subworker gets its own top-bar dot with a monogram, ring-colored by state.

Run popup animation

When an agent starts, its photo drops from the menu bar icon with a live chat bubble streaming output — visible over fullscreen video, auto-retracts, configurable duration.

Full LogViewer

Sessions, messages, reasoning, tool calls, live stream — click any agent photo to open the session browser, always clamped inside the screen.

One-click triggers

Manual Run dropdown, enable/disable, next run, schedule — everything from the menu, no terminal needed.

Topbar Settings

Agent photos side, live padding slider, run animation duration + test trigger — zero permissions required.

Server health

Connection state, PID, restart count, running/total agents — at a glance, with one-click reconnect.

Colima container management

Start, stop, restart instances. Open a shell, inspect resources, delete, auto-refresh — plus launch at login. Full Docker container control from your menu bar.

Architecture

Thin client, powerful engine

EliaTopBar is the control surface. EliaAgent is the engine. The app renders, the server decides.

EliaTopBar Swift 5.9

  • Menu bar icon with dynamic state ring
  • Per-agent monogram dots in the status bar
  • Run popup: photo drop + live chat bubble
  • Click-to-open full LogViewer
  • Manual trigger, enable/disable, schedules
  • Colima instance management
WebSocket
ws://localhost:5656/ws
HTTP
/status /trigger /logs

EliaAgent FastAPI

  • Subworker scheduler — cron or manual trigger
  • WebSocket events: initial_status, subworker_started
  • run_log streaming, subworker_completed, pong
  • REST endpoints: /status, /trigger, /enable
  • Log storage and session management
  • Docker-based — runs in Colima or any Docker host
Quick Start

Up and running in three steps

1

Download

Grab EliaTopBar-vX.Y.Z-arm64.dmg from the latest release, open it and drag EliaTopBar to Applications.

2

First launch

Ad-hoc signed, not notarized: right-click the app → Open, then confirm. Stubborn?
xattr -dr com.apple.quarantine

3

Connect

Start EliaAgent on localhost:5656. EliaTopBar auto-connects — no config, no env vars.

Build from source
$ git clone https://github.com/vakandi/Elia-Topbar.git
$ cd Elia-Topbar
$ ./build-app.sh # universal arm64 + x86_64, ad-hoc signed
$ open EliaTopBar.app
Requirements

What you need

RequirementDetail
macOS13.0+ (Ventura or newer), Apple Silicon
Swift toolchain5.9+ (only for building from source)
EliaAgentFastAPI server, default localhost:5656 (optional — for subworker features)
Colimabrew install colima (optional — only for container management)
First launch note: EliaTopBar is ad-hoc signed, not notarized by Apple. On first launch macOS shows an "unidentified developer" warning. Right-click the app in Applications and choose Open, then confirm. If macOS still refuses: xattr -dr com.apple.quarantine /Applications/EliaTopBar.app
